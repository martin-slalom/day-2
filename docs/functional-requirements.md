# Functional Requirements

## TODO App Core Requirements

1. The user can create a new task with a required title.
2. The user can optionally add a description to a task.
3. The user can optionally assign a due date to a task.
4. The user can mark a task as complete.
5. The user can mark a completed task as active again.
6. The user can edit an existing task title, description, and due date.
7. The user can delete an individual task.
8. The user can view tasks grouped by status: active and completed.
9. The user can filter tasks by status: all, active, and completed.
10. The user can sort tasks by due date (earliest first), then by creation time.
11. The user can clear all completed tasks in one action.
12. The user can search tasks by title and description text.
13. The app validates that task titles are not empty.
14. The app persists tasks so they are available after a page refresh.
15. The app displays overdue tasks clearly when the due date is in the past and the task is not completed.
